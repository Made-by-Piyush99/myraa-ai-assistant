🌐 Local Server (Port 3002)

MYRAA app automatically starts a high-speed local HTTP & REST Server on port 3002 directly inside your phone. You can access it on this device or from your PC on the same Wi-Fi network!

Localhost URL (Phone Browser)

http://localhost:3002

Wi-Fi Network URL (For PC & Others)
